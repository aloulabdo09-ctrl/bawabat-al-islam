# بوابة الإسلام — نموذج أولي Flutter

هذا مشروع بداية (MVP UI prototype) لتطبيق متعدد المنصات باستخدام Flutter.

## ما يتضمنه
- واجهة عربية من اليمين إلى اليسار.
- هوية بصرية أخضر داكن وذهبي.
- تنقل سفلي بين الرئيسية والقرآن والتعلّم والتعريف بالإسلام والمزيد.
- بطاقات أولية للأقسام ومحتوى تعريفي تجريبي.

## ما لا يتضمنه بعد
هذا ليس إصداراً إنتاجياً: لا توجد بعد قاعدة بيانات، أو نص قرآني كامل، أو ملفات صوت، أو ترجمات موثقة، أو نظام بحث، أو مساعد ذكاء اصطناعي، أو مواقيت صلاة فعلية.

## التشغيل
1. ثبّت Flutter SDK وAndroid Studio أو Xcode.
2. أنشئ مشروعاً جديداً:
   `flutter create bawabat_al_islam`
3. استبدل `lib/main.dart` بالملف الموجود في هذا المشروع.
4. من مجلد المشروع نفّذ:
   `flutter run`

## الخطوات التالية قبل النشر
- ربط نص المصحف ومراجعة مصدره والترجمات والتفاسير وتراخيصها.
- بناء نظام محتوى وإدارة مراجعة علمية.
- إضافة التعدد اللغوي واختبار RTL/LTR.
- إضافة مصادر الحديث والتخريج ودرجات الأحاديث.
- بناء البحث والمفضلة والعمل دون اتصال.
- إضافة مساعد أسئلة مقيد بمصادر موثقة ومراجعة بشرية.
- سياسة خصوصية وإمكانية الوصول واختبارات أمنية.
